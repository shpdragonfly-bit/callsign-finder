FLT Package 분석

  1. 패키지 선택PDF 파일
  2. 분석기본 · AI
  3. 요약 PDF저장 · 공유

API 없이 · 오프라인

  • 몇 초 안에 끝나고 무료
  • 패키지가 기기 밖으로 나가지 않음

  • 정해 둔 항목만 추출 · 문장 요약과 중요도 판단은 못 함
  • 패키지 양식이 바뀌면 앱 업데이트 전까지 해당 항목은 ‘확인 필요’

  1. 근무표 선택PDF 파일
