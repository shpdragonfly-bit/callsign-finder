Gemini AI 연결

AI 분석 기능을 쓰려면 본인 Gemini API 키를 한 번 등록합니다.

미연결
1API 키가 뭔가요?

API 키는 ‘이 앱에서 내 구글 계정으로 제미나이(Gemini) AI를 쓰게 해 주는 출입증’입니다. 길고 복잡한 영문·숫자 조합으로 되어 있습니다.

구글 계정(Gmail)만 있으면 무료로 받을 수 있고, 한 번 등록하면 이 기기에서 계속 쓸 수 있습니다.

비밀번호처럼 다루세요. 남이 알면 내 무료 사용량을 대신 쓸 수 있습니다.

2API 키 받는 방법 (따라하기)

이 앱을 쓸 휴대폰·패드에서 직접 받아 붙여넣는 것이 가장 안전하고 쉽습니다.

  1. 아래 [Google AI Studio 열기] 버튼을 누릅니다.
  2. 구글 계정(Gmail)으로 로그인합니다.
  3. 처음이면 이용약관 화면이 나옵니다. 동의에 체크하고 계속 누릅니다. 이때 키가 자동으로 하나 만들어지기도 합니다.
  4. API Keys(API 키) 화면에 키가 보이면 그 키를 씁니다. 없으면 Create API key(API 키 만들기)를 누릅니다.
  5. 키 옆의 복사 버튼(겹친 네모 모양)을 누릅니다.
  6. 이 앱으로 돌아와 아래 입력칸을 길게 눌러 붙여넣기합니다.
  7. [저장하고 연결 확인]을 누르고, 위에 ‘연결됨’이 나오면 끝입니다.

결제(Billing) · 카드 등록 화면이 나오면 누르지 마세요. 키를 받는 데 결제는 필요 없습니다.

3안전하게 쓰는 법 (꼭 읽어 주세요)
  • 무료로만 쓰세요. AI Studio나 Google Cloud에 결제 정보(카드)를 등록하지 마세요. 결제를 등록하지 않으면 키가 새어 나가도 요금이 나오지 않습니다. 최악의 경우라도 그날 무료 사용량이 먼저 소진될 뿐입니다.
  • 호텔 · 공항 · 카페 와이파이처럼 여러 사람이 함께 쓰는 와이파이에서는 키가 노출될 가능성을 완전히 막을 수 없습니다. 키는 언제든 노출될 수 있다고 생각하고, 그래서 꼭 무료로만 쓰세요.
  • 키를 카톡 · 문자 · 메일로 보내거나 화면을 찍어 공유하지 마세요.
  • 키는 이 기기 안에만 저장됩니다. 앱 제작자를 포함해 어디에도 보내지 않고, AI 분석을 요청할 때만 구글로 직접 전달됩니다.
  • 새어 나간 것 같으면: AI Studio의 API Keys 화면에서 그 키를 삭제하고 새 키를 만든 뒤, 이 앱에서 [지우기]를 누르고 새 키를 등록하세요.

구글 캘린더 연결

구글 캘린더 연결 안내 시험판

연결은 선택입니다. 연결하지 않아도 이 앱 안에서 월별로 볼 수 있습니다.

준비 중
1연결하면 무엇이 달라지나요?

내 구글 계정에 ‘FLT 근무표’라는 캘린더를 새로 만들고, 근무표 일정을 그 캘린더에만 넣습니다.

  • 앱은 ‘FLT 근무표’ 캘린더만 다룹니다. 기존 개인 일정은 보지도 고치지도 못합니다.
  • 일정은 내 구글 계정에만 들어갑니다. 앱 제작자도 볼 수 없습니다.
  • 휴대폰 기본 캘린더 · 위젯 · 알림에서 근무표를 볼 수 있습니다.

연결하지 않으면 이렇게 됩니다: 휴대폰 캘린더 · 위젯 · 다른 캘린더 앱에는 안 보이고, 출근 전 알림을 쓸 수 없으며, 근무표는 이 앱을 열어야 볼 수 있습니다. 나중에 언제든 연결할 수 있습니다.

2준비물
  1. 구글 계정(Gmail) 하나 — 근무표를 넣을 계정입니다.
  2. 따로 신청할 필요 없이 본인이 직접 연결하면 됩니다. 연결이 안 되거나 어려우면 ☰ 메뉴 → 사용자 요청에 ‘구글 캘린더 연결 안 됨’과 화면에 나온 문구를 적어 보내 주세요.
  3. 근무표 파일: 회사에서 받은 원본 PDF(가장 정확) 또는 화면 캡처 사진(Gemini 키 등록자만, 확인 필요).

이 앱이 쓰는 권한은 구글 분류상 ‘민감하지 않은 범위’입니다. 그래서 구글 검토나 인원 제한 없이 누구나 자기 구글 계정으로 연결할 수 있습니다. 구글 계정이 없거나 연결이 안 되는 분은 일정 파일(.ics)로 넣는 방법을 함께 준비합니다.

3연결 순서 (따라하기)
  1. 이 화면의 [구글 캘린더 연결] 버튼을 누릅니다. (시험판 준비가 끝나면 열립니다)
  2. 구글 계정 선택 창에서 근무표를 넣을 계정을 고릅니다.
  3. 혹시 ‘Google에서 확인하지 않은 앱’ 화면이 나오면 왼쪽 아래 [고급] → [FLT Assist(으)로 이동]을 누릅니다. ‘액세스 차단됨’이 나오면 ☰ 메뉴 → 사용자 요청으로 알려 주세요.
  4. 권한 화면에서 ‘이 앱이 만든 캘린더 보기·관리’ 항목만 있는지 확인하고 체크한 뒤 [계속]을 누릅니다. 다른 권한(메일 · 연락처 · 모든 캘린더 등)을 묻는다면 누르지 말고 알려 주세요.
  5. 앱으로 돌아와 위쪽이 ‘연결됨’으로 바뀌면 끝입니다. 내 구글 캘린더에 ‘FLT 근무표’ 캘린더가 생깁니다.

창이 안 뜨면: 아이폰 Safari는 설정 → 앱 → Safari → 팝업 차단을 잠시 끄고 다시 누르세요. 홈 화면에 추가한 앱에서 안 되면 Safari에서 이 앱 주소를 열어 연결해 보세요.

4휴대폰 캘린더에서 보이게 하기

안드로이드 · 구글 캘린더 앱

  1. 구글 캘린더 앱 → 왼쪽 위 ☰
  2. 근무표를 넣은 계정 아래 ‘FLT 근무표’에 체크

아이폰 · 기본 캘린더 앱

  1. 설정 → 앱 → 캘린더 → 캘린더 계정에 그 Gmail 계정이 있고 ‘캘린더’가 켜져 있는지 확인 (없으면 계정 추가 → Google)
  2. 캘린더 앱 아래 [캘린더] → ‘FLT 근무표’ 체크
  3. 보이지 않으면 PC나 Safari에서 calendar.google.com/calendar/syncselect 를 열어 ‘FLT 근무표’에 체크하고 저장

구글 캘린더 앱(아이폰용)을 설치하면 위 과정 없이 바로 보입니다.

5안전하게 쓰는 법 (꼭 읽어 주세요)
  • 공용 기기(사무실 PC · 호텔 PC)에서는 연결하지 마세요.
  • 로그인은 보안상 약 1시간 뒤 자동으로 풀립니다. 근무표를 넣을 때만 다시 로그인하면 되고, 이미 넣은 일정은 그대로 남습니다.
  • ‘FLT 근무표’ 캘린더에는 직접 일정을 넣지 마세요. 근무표를 다시 넣을 때 그 기간의 일정이 새 근무표로 바뀝니다. 개인 일정은 다른 캘린더에 넣으세요.
  • 앱이 다루는 것은 ‘FLT 근무표’ 캘린더뿐이라, 이 캘린더를 지워도 개인 일정에는 영향이 없습니다.
  • 연결 끊기: 구글 계정 관리 → 보안 → 서드파티 앱 및 서비스 → FLT Assist → 액세스 권한 삭제. 이미 넣은 일정을 지우려면 구글 캘린더에서 ‘FLT 근무표’ 캘린더를 삭제하세요.
  • 사진으로 읽은 근무표는 틀릴 수 있습니다. 넣기 전 미리 보기에서 꼭 확인하고, 운항 판단은 회사 원본 근무표로 하세요.
6Apple 캘린더만 쓰는 경우

구글 계정 없이 일정 파일(.ics)로 넣는 방법을 함께 준비합니다. 앱이 만든 파일을 열고 넣을 캘린더를 고른 뒤 ‘모두 추가’를 누르면 됩니다.

일정 파일 방식은 근무표가 바뀌면 이전에 넣은 일정을 직접 지워야 할 수 있습니다. 바뀐 것만 고쳐 주는 기능은 구글 캘린더 연결에서만 됩니다.

구글 캘린더와 Apple용 일정 파일(.ics)의 비행 일정에 휴대폰 알림을 넣습니다.

  • 연결 코드는 서버로 보내지 않습니다. 연결 코드를 잃어버리면 서버 사본은 아무도 열 수 없습니다.
  • 지난달부터 다음 두 달까지(4개월)만 보내고, 120일 동안 쓰지 않으면 자동으로 지워집니다.
  • 근무표를 저장하거나 지우면 자동으로 보내고, 앱을 열 때 다른 기기에서 고친 것을 받아 옵니다. 두 기기에서 고쳤으면 나중에 고친 쪽으로 맞춥니다.
  • 끄면 서버 사본을 바로 지웁니다. 이 기기의 근무표는 그대로 남습니다.

다른 기기에서 쓰려면: 그 기기에서 왼쪽 위 아이디 → ‘다른 기기에서 쓰던 아이디로 바꾸기’에 같은 연결 코드를 넣고, 이 화면에서 동기화를 켜면 근무표를 받아 옵니다.

켜지 않으면: 기기마다 근무표를 따로 넣어야 합니다. 구글 캘린더에 연결했다면 휴대폰 캘린더에서는 어느 기기든 보입니다. 나중에 언제든 켤 수 있습니다.

근무표 공유 그룹 시험판

동료·가족과 월 근무표를 공유. 그룹당 4명, 한 사람 5개 그룹까지. 그룹마다 공개 범위(근무/휴무만 · 상세) 선택.

  • 초대는 상대의 앱 아이디(왼쪽 위 6자리)를 넣어 만듭니다. 초대 코드가 다른 사람에게 가도 그 아이디만 참가할 수 있고, 24시간 뒤 만료됩니다.
  • 초대받으려면 먼저 이 화면에서 공유 시작을 눌러 내 아이디를 등록해야 합니다.
  • 공유 내용은 그룹 비밀키로 기기에서 암호화되어 서버·앱 제작자는 볼 수 없습니다. 비밀키는 초대 코드 안에만 있습니다.
  • 지난달~다음 두 달(4개월)만 올라가고, 근무표를 저장하면 자동으로 갱신됩니다. 나가면 내 공유본은 서버에서 바로 지워집니다.
  • 근무/휴무만: 날짜별 근무·휴무만 보입니다. 상세: 편명·구간·시각까지 보입니다. 메모·출근 시각 설명은 어느 쪽도 올리지 않습니다.
  • 그룹을 만든 사람(관리자)만 초대·내보내기를 할 수 있습니다. 내 기기 동기화를 켜면 다른 내 기기에도 그룹이 함께 옮겨집니다.
