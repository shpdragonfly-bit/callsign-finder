FLT Assist 개인정보처리방침

시행일 2026-10-12 · 앱 주소 https://shpdragonfly-bit.github.io/callsign-finder/

1. 기본 원칙

  • FLT Assist(운항 도우미)는 회원 가입이 없고, 이름 · 전화번호 · 이메일 주소를 수집하지 않습니다.
  • 입력한 내용과 설정은 기본적으로 사용자 기기 안에만 저장됩니다.
  • 사용자 정보를 판매하거나 광고에 쓰지 않습니다.

2. Google 캘린더 연결 (선택)

  • 사용자가 직접 연결을 누른 경우에만 Google 계정 로그인 창을 엽니다.
  • 요청하는 권한은 calendar.app.created 하나입니다. 이 앱이 만든 ‘FLT 근무표’ 캘린더를 만들고, 그 캘린더의 일정만 보기 · 만들기 · 고치기 · 지우기 합니다. 사용자의 다른 캘린더와 일정에는 접근하지 않습니다.
  • Google이 주는 접근 토큰은 그 기기에만 저장하며(약 1시간 유효), 앱 제작자나 다른 서버로 보내지 않습니다. 캘린더 일정은 사용자 본인의 Google 계정에만 저장됩니다.
  • 연결 해제: Google 계정 → 보안 → 서드파티 앱 및 서비스 → FLT Assist → 액세스 권한 삭제. ‘FLT 근무표’ 캘린더를 지우면 앱이 넣은 일정도 모두 지워집니다.
  • Google API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 근무표

  • PDF 근무표는 기기 안에서 읽고, 파일을 밖으로 보내지 않습니다.
  • 사진(화면 캡처) 근무표는 사용자가 등록한 본인 Gemini API 키로 Google Gemini에 보내 읽습니다. 이 경우 사진이 Google로 전송된다는 안내와 동의를 먼저 받습니다.
  • 내 기기 간 동기화 · 공유 그룹(사용자 선택 기능)은 일정을 기기에서 암호화(내 아이디의 연결 코드 또는 그룹 비밀키)한 뒤 서버에 보관하며, 서버와 운영자는 내용을 볼 수 없습니다. 서버에는 앱 아이디(무작위 6자리), 본인 확인용 해시, 그룹 멤버 아이디, 암호화된 일정만 저장됩니다. 보관 범위는 지난달부터 다음 두 달까지이고 120일 동안 갱신이 없으면 자동 삭제되며, 기능을 끄거나 그룹에서 나가면 서버 사본을 바로 지웁니다.

4. Gemini API 키 (FLT Package 분석, 선택)

  • 사용자가 입력한 Gemini API 키는 그 기기에만 저장되며, 분석을 요청할 때 Google로만 직접 전달됩니다.

5. 익명 사용 통계 · 사용자 요청

  • 기능 개선을 위해 어떤 기능을 썼는지(예: 실행, 검색 횟수)와 앱 버전 같은 익명 통계를 모읍니다. 편명 · 공항 · 이름 · 위치 · 앱 아이디는 보내지 않습니다.
  • ☰ 메뉴 → 사용자 요청에 적어 보낸 내용은 답변과 개선에만 씁니다.
  • 비행준비(공항별 유의사항)는 기기마다 만든 무작위 번호로 하루 조회 수만 셉니다.

6. 문의

앱의 ☰ 메뉴 → 사용자 요청으로 보내 주세요.
