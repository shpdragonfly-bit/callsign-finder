# 운항 도우미 (Flight Assist) 사용 설명서

운항 중 인터넷이 없어도 쓸 수 있는 조종사용 웹앱입니다. 기능은 두 가지입니다.

- **Call Sign 조회**: Call Sign을 넣으면 출발·도착 공항, 운항 기종, 운항 스케줄, 공항 표고, 일출·일몰 시각을 보여줍니다. 공항 코드로 그 공항을 오가는 편을 거꾸로 찾을 수도 있습니다.
- **비행시간계산**: 편조 구성(3 Pilot · 2 Set · 5 Pilot)에 맞춰 근무·휴식 구간을 균등하게 나누고, 근무 교대 시각을 보여줍니다.

지원 항공사는 **대한항공 · 진에어 · 제주항공 · 티웨이**입니다.

> 이 앱의 자료는 공개 데이터를 모은 **참고용**입니다. 실제 운항 기종·노선·시각은 당일 운항 정보와 다를 수 있으니, 공식 운항 정보를 대체하지 않습니다.

## 1. 설치하기 (처음 한 번, 인터넷 연결 필요)

접속 주소: **https://shpdragonfly-bit.github.io/callsign-finder/**

### iPhone / iPad
1. 반드시 **Safari**로 위 주소를 엽니다. 크롬이나 카카오톡 안의 브라우저로는 오프라인 저장이 되지 않습니다.
2. **공유 버튼**(네모에 위쪽 화살표)을 누릅니다. 아이폰은 화면 아래, 아이패드는 주소창 오른쪽에 있습니다.
3. **홈 화면에 추가**를 누르고, 오른쪽 위 **추가**를 누릅니다.
4. 홈 화면에 **운항도우미** 아이콘이 생깁니다.

### Android
1. **Chrome**으로 위 주소를 엽니다.
2. 오른쪽 위 **⋮** 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 누릅니다.
3. 홈 화면이나 앱 목록에 **운항도우미** 아이콘이 생깁니다.

### 설치 직후 꼭 할 일
홈 화면 아이콘으로 앱을 **한 번 열었다 닫아 주세요.** 이때 앱 화면과 데이터가 기기에 저장되어, 이후 인터넷 없이도 열립니다.

## 2. 운항 전과 운항 중

| 시점 | 할 일 |
|---|---|
| **운항 전** (인터넷 O) | 아이콘으로 앱을 엽니다. 최신 자료가 자동으로 저장됩니다. 확실히 하려면 Call Sign 조회 탭 아래 **최신 데이터 받기**를 누릅니다. |
| **운항 중** (비행기 모드) | 아이콘으로 엽니다. 상단에 **오프라인**이 표시되고, 저장된 자료로 모든 기능이 동작합니다. |

- 하단 **데이터 기준** 시각으로 자료가 언제 것인지 확인할 수 있습니다. 7일이 지나면 "(N일 경과)" 경고가 나옵니다.
- 운항 전에 앱을 열지 않아도 **마지막으로 저장된 자료**로 쓸 수 있습니다. 다만 그만큼 오래된 자료입니다.
- 자료는 서버에서 **6시간마다** 자동으로 갱신됩니다.

## 3. Call Sign 조회

### 항공사 선택
검색창 위의 **대한항공 · 진에어 · 제주항공 · 티웨이** 탭에서 고릅니다. 처음에는 대한항공이 선택돼 있고, 마지막에 고른 항공사는 기억됩니다. 항공사를 바꾸면 화면 색도 함께 바뀝니다.

| 항공사 | ICAO / IATA | 무선호출부호 | 화면 색 |
|---|---|---|---|
| 대한항공 | KAL / KE | KOREANAIR | 하늘색 |
| 진에어 | JNA / LJ | JIN AIR | 연두색 |
| 제주항공 | JJA / 7C | JEJU AIR | 주황색 |
| 티웨이 | TWB / TW | TEEWAY | 빨간색 |

### 편명으로 찾기
아래 형식을 모두 같은 편으로 알아듣습니다. 앞자리 0은 무시합니다.

- `KAL017`, `KAL17` (ICAO)
- `KE17`, `KE017` (IATA)
- `KOREANAIR 17` (무선호출부호)
- `17` (숫자만 넣으면 **선택한 항공사** 편)

다른 항공사 편명을 직접 넣으면(예: 대한항공 탭에서 `7C101`) 그 항공사 탭으로 자동 전환됩니다.

### 조회 결과 (위에서부터)
1. **Call Sign**과 편명
2. **출발 → 도착 공항**: IATA·ICAO 코드, 공항 이름, 도시. 경유편은 전체 경로도 표시
3. **운항 기종**: 예) B748 Boeing 747-8
   - 실제 비행 관측(ADS-B)으로 확인된 기종을 우선 보여줍니다.
   - 관측이 없으면 공항 스케줄의 예정 기종을 보여줍니다.
4. **운항 스케줄**
   - 운항 요일: 월~일 중 운항하는 요일이 강조되고 "매일" 또는 "주 N회"로 표시
   - 다가오는 운항편: 예정 시각(UTC·KST), 지연 시 변경 시각, 예정 기종·등록부호(HL…)·게이트, 결항·지연 표시
   - 국내선 시즌 스케줄: 출발·도착 예정 시각
5. **표고 · 일출·일몰 (UTC)**: 출발·도착 공항의 표고(ft)와 일출·일몰 시각
   - **오늘 / 내일** 버튼으로 공항 현지 날짜 기준 하루를 바꿔 볼 수 있습니다.
   - 공항 좌표로 기기에서 직접 계산해서 오프라인에서도 나옵니다. 오차는 1~2분 정도입니다.

### 공항 코드로 거꾸로 찾기
검색창에 **IATA 3자리**(`LAX`)나 **ICAO 4자리**(`KLAX`)를 넣으면, 선택한 항공사의 그 공항 편이 나옵니다.

- 공항 이름, 표고, 일출·일몰
- **출발 / 도착 / 경유**로 나눈 목록. 개수가 함께 나오고, 제목을 누르면 접고 펼 수 있습니다.
- 다음 예정 시각이 빠른 순서로 정렬됩니다. 예: `KAL18 → ICN · 10/8 0850Z · B748`
- 목록에서 편을 누르면 그 편의 상세 조회로 넘어갑니다.

### 비슷한 Call Sign / 최근 조회
입력 중에는 앞자리가 같은 Call Sign이 아래에 나오고, 입력창이 비어 있으면 최근 조회한 편이 나옵니다.

## 4. 비행시간계산

### 기본 사용 순서
1. **편조 구성**을 고릅니다: **3 Pilot / 2 Set / 5 Pilot**
2. **구간 방식**을 고릅니다. 3 Pilot은 4구간·7구간, 2 Set은 3구간·5구간, 5 Pilot은 5구간입니다.
3. **전체 비행시간**을 넣습니다. 아래 형식이 모두 됩니다.
   - 시간·분 칸에 따로: `12` / `30`
   - 시간 칸에 `1230` (네 자리)
   - 시간 칸에 `12+30`
4. 균등 배분된 근무·휴식 구간이 바로 계산됩니다.

### 공통 원칙
- 조종석에는 항상 **2명**이 근무합니다.
- 모든 인원의 조종석 근무시간을 **똑같이** 맞추는 것이 대원칙입니다.
- 이륙·착륙은 지정된 편조가 합니다.
- **착륙 전 마지막 구간은 기본 1+30**이고, 최소 1+00을 확보합니다. 1+00보다 짧으면 입력칸이 빨간색으로 바뀝니다.

### 편조별 규칙

**3 Pilot — C1(PC), C2(NC), F(NF)**
- 이륙·착륙은 C1·F, 첫 휴식은 F, 착륙 전 마지막 휴식은 C1입니다.
- **4구간**: C1·F(이륙) → C1·C2 → C2·F → C1·F(착륙)
  - 예) 12+30 → 2+40 / 4+10 / 4+10 / 1+30, 각자 근무 8+20
- **7구간**: 4구간 중간에 휴식이 한 번씩 더 들어가는 방식으로, 연속 근무가 짧아집니다.
  - 예) 12+30 → 1+00 / 2+05 / 2+05 / 1+40 / 2+05 / 2+05 / 1+30

**2 Set — C1(JC)·F1(GF) / C2(GC)·F2(GF)**
- 이륙·착륙은 C1·F1 편조, 두 편조 근무시간 동일
- **3구간**: C1·F1 → C2·F2 → C1·F1
  - 예) 12+30 → 4+45 / 6+15 / 1+30
- **5구간**: C1·F1 → C2·F2 → C1·F1 → C2·F2 → C1·F1
  - 예) 12+30 → 2+25 / 3+10 / 2+20 / 3+05 / 1+30

**5 Pilot — C1, C2, C3, F1, F2**
- 이륙·착륙은 C1·F1 편조이고, 이 편조는 이륙·착륙 구간에만 근무합니다.
- 순서: C1·F1(이륙) → C2·F2 → C2·C3 → C3·F2 → C1·F1(착륙)
- 5명이 각각 전체의 2/5를 근무합니다. 가운데 세 구간은 각 1/5입니다.
  - 예) 12+30 → 3+30 / 2+30 / 2+30 / 2+30 / 1+30, 각자 근무 5+00

### 구간 수동 조정
- 각 구간의 **− / +** 버튼(5분 단위)을 누르거나 시간을 직접 입력합니다.
- 나머지 구간은 전체 비행시간에 맞게 자동으로 다시 나눠집니다.
  - 이륙 후 구간과 착륙 전 구간 중 하나를 바꾸면 다른 쪽이 맞춰져서 균등이 유지됩니다.
  - 가운데 구간을 바꾸면 균등이 깨질 수 있고, 아래 요약에서 근무시간 차이를 바로 볼 수 있습니다.
- **기본값으로** 버튼을 누르면 처음 배분으로 돌아갑니다.
- 아래 요약에는 사람(또는 편조)별 **근무 · 휴식 · 최대 연속 근무**가 나옵니다.

### 운항 시각과 근무 교대 시각
**운항 시각 (UTC)** 칸에 R/O · T/O · L/D · R/I를 넣습니다. `1430`처럼 네 자리로 넣고, 각 칸의 **지금** 버튼을 누르면 현재 UTC가 들어갑니다.

| 항목 | 계산 |
|---|---|
| **FLT Time** | L/D − T/O |
| **Block Time** | R/I − R/O |

- 자정을 넘겨도 맞게 계산합니다. FLT·Block Time은 비행 후 기록용이라 계획 비행시간에는 영향을 주지 않습니다.
- **T/O**를 넣으면 구간 사이에 **근무 교대 띠**가 나타납니다.
  - 교대 시각을 **KLT(Korea Local Time, UTC+9)**로 크게 보여주고, 옆에 UTC를 작게 붙입니다.
  - 누가 근무에 들어가고 누가 휴식에 들어가는지 함께 표시합니다. 예) `교대 0210 KLT 1710Z · C2 근무 · F 휴식`
  - 마지막 구간 끝은 착륙이라 교대 띠를 표시하지 않습니다.
- 그래프의 시간축과 각 구간의 시각도 UTC로 바뀝니다. 자정을 넘기면 `+1`이 붙습니다.

### 입력값 유지
탭을 바꾸거나 앱을 껐다 켜도 입력값과 조정값이 그대로 남아 있습니다. 편조와 구간 방식마다 조정값이 따로 저장됩니다.

## 6. 자주 묻는 질문

**Q. 오프라인에서 화면이 안 열려요.**
설치한 뒤 인터넷이 될 때 홈 화면 아이콘으로 한 번 이상 열어야 저장됩니다. iPhone은 Safari로 설치해야 합니다.

**Q. 홈 화면 아이콘을 지웠더니 자료가 없어요.**
아이콘을 지우면 저장된 자료도 함께 지워집니다. 다시 설치한 뒤 인터넷 되는 곳에서 한 번 열면 됩니다.

**Q. 아이콘 이름이 "CallSign"으로 보여요.**
예전 버전으로 설치된 것입니다. 아이콘을 지우고 다시 추가하면 "운항도우미"로 바뀝니다.

**Q. 기종이 "기종 미확인"으로 나와요.**
아직 관측 자료와 스케줄 자료가 없는 편입니다. 자료는 6시간마다 쌓이니, 며칠 지나면 채워지는 편이 늘어납니다.

**Q. 해외 출발 → 해외 도착 구간의 스케줄이 안 보여요.**
스케줄 자료는 한국 공항(인천, 김포, 김해, 제주 등)을 오가는 편만 공개되어 있어서, 해외 구간은 노선과 기종만 나옵니다.

**Q. 동료에게 공유하려면?**
접속 주소만 알려주면 됩니다. 계정이나 가입은 필요 없습니다.

## 8. 관리자용 안내

### 구성
| 경로 | 내용 |
|---|---|
| `web/` | 앱 화면(`index.html`), 데이터(`data.json`, `data.js`), 오프라인 캐시(`sw.js`), 설치 정보(`manifest.webmanifest`) |
| `updater/update.py` | 노선·공항·기종 수집 후 `web/data.*` 생성 (Python 3.8+, 표준 라이브러리만 사용) |
| `updater/public_schedule.py` | 공공데이터 운항 스케줄 수집. 마지막 성공값은 `data/public_cache.json`에 보관 |
| `config/airlines.json` | 대상 항공사 목록 (`enabled: true`인 항공사만 수집·표시) |
| `config/overrides.csv` | 노선·기종 수동 보정. 화면에 "수동 지정"으로 표시 |
| `data/observations.json` | ADS-B 기종 관측 누적 (120일 보관) |
| `.github/workflows/update.yml` | 6시간마다, 그리고 코드 변경 시 자동 갱신 후 GitHub Pages로 배포 |
| `.github/workflows/probe.yml`, `tools/` | 공공데이터 API 점검용 (수동 실행) |

### 자동 갱신 설정
- **배포**: 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 둡니다.
- **인증키**: 저장소 **Settings → Secrets and variables → Actions**에 `DATA_GO_KR_KEY`(공공데이터포털 인증키, Decoding 값)를 등록합니다. 키가 없으면 스케줄 수집만 건너뜁니다.
- **필요한 공공데이터 활용신청**
  - 인천국제공항공사 항공기 운항 현황 상세 조회
  - 한국공항공사 항공기 운항 스케줄 정보 GW
- 한국공항공사 API는 한 번에 100건 이하로 요청해야 합니다. 초과하면 HTTP_ERROR가 납니다.
- **수동 실행**: Actions 탭 → `update-callsign-data` → **Run workflow**

### 항공사 추가
1. `config/airlines.json`에 항목을 추가하거나 `enabled`를 `true`로 바꿉니다. 필요한 값은 ICAO 3자리, IATA 2자리, 무선호출부호, 이름입니다.
2. 그 항공사 보유 기종이 `type_sweep` 목록에 없으면 추가합니다.
3. 화면 탭 이름과 색상은 `web/index.html`의 `SHORT` 목록과 `[data-al="..."]` 색상 규칙에서 지정합니다.

- **Mac/Linux**: `./update.sh`
